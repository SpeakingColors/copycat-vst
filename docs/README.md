# Mockups

Interactive HTML mockups of Copycat. Open any file in a browser, keep `support.js` next to it. Knobs, faders and buttons respond, but nothing makes sound or talks to hardware yet. Fonts load from Google Fonts when online.

- [Copycat](mockups/Copycat.dc.html)
- [Copycat (interactive, current)](mockup/copycat.html): download and open in a browser. Plays real test audio. The older v1 pages are in [mockups](mockups/).
